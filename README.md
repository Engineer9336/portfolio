# Aryan Mishra — Personal Portfolio

A responsive, fresher-friendly AI/ML portfolio built with HTML, CSS and JavaScript.

## Included
- Responsive modern dark/AI-themed design
- About, skills, projects, education, achievements, certifications and contact sections
- Project screenshots supplied by the portfolio owner
- Resume link
- GitHub, LinkedIn and GeeksforGeeks links
- Mobile navigation and subtle scroll animations

## Main files
- `index.html`
- `style.css`
- `script.js`
- `assets/`

## Deploy with GitHub Pages
1. Create a public GitHub repository.
2. Upload the contents of this folder so `index.html` is in the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose **main** and **/(root)**.
6. Save and wait for GitHub Pages to publish.
